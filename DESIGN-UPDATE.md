# Approved design

Home uses an Ocean Blue summary, six pastel tools in three columns, recent files and Home/Files/History navigation. Shared components provide blue actions, neutral surfaces, consistent typography and rounded cards.

Split and PDF to Image use compact file rows and consolidated settings. All tools use a bottom result sheet. Split outputs are individual PDF files; returning after opening any result goes to Home.

The viewer has slim controls, horizontal page swiping, zoom/pan and true fullscreen. Settings contains History, Privacy policy, Share app, Review app and version. The approved exit dialog is compact and left aligned with Stay and Exit buttons. The Settings gear is symmetrical with a pale blue background.

Version 0.3.0 consolidates the app and removes design fixtures and the alternate review build. Original mockups remain in design/ as references. Historical APK measurements do not describe this current build.
